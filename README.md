# Noor Alam Wedding Invitation

Static site, no build step. Entry point: index.html

## Upload to GitHub Pages
1. On github.com create a new repository (Public).
2. Click "uploading an existing file" and drag in everything INSIDE this site folder: index.html, support.js, .nojekyll, README.md and the assets folder. index.html must be at the top level of the repo.
3. Commit the upload.
4. Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
5. After a minute, open https://USERNAME.github.io/REPO/

## Notes
- Must be opened over https (GitHub Pages does this). Double-clicking index.html will not load the video.
- Music: assets/song.mp3, starts when the guest taps the wax seal.
- Hero video: assets/hero-bride2.mp4
- Fonts load from Google Fonts, so guests need an internet connection to see them.
- Do not edit support.js.
